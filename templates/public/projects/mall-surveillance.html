Case Study

Mall Surveillance System

Real-time AI-powered surveillance with face recognition, object detection, and anomaly alerts for a commercial mall environment.

Computer Vision Deep Learning Deployed

Technology Stack

PythonOpenCVTensorFlow PostgreSQLDockerREST API

The Problem

A commercial mall needed an intelligent surveillance system that could go beyond traditional CCTV. The existing system required constant human monitoring, missed incidents, and had no ability to identify persons of interest or detect unusual behavior patterns.

Challenges

  • →Processing multiple camera feeds simultaneously in real-time without frame drops
  • →Achieving high accuracy face recognition in varying lighting conditions
  • →Minimizing false positives in anomaly detection to avoid alert fatigue
  • →Building a scalable architecture that could handle camera expansion

Architecture

The system uses a multi-threaded Python backend with OpenCV for video capture and preprocessing. Each camera feed runs in an isolated thread, feeding frames into a TensorFlow inference pipeline.

Camera Feeds → Frame Buffer → Preprocessing → Detection Pipeline → Alert Engine → Dashboard

Implementation

Built a custom face recognition model trained on a curated dataset. Object detection uses a fine-tuned YOLO model for real-time performance. Anomaly detection uses behavioral pattern analysis with configurable thresholds.

Lessons Learned

Multi-threading in Python requires careful GIL management for CPU-bound tasks. Using separate processes for inference and a shared queue for frames significantly improved throughput. Model quantization reduced inference time by 40% with minimal accuracy loss.
